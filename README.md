# Práctica IA

Simulador de exámenes de Ingeniería de Software asistida por IA con 241 preguntas.

## Publicar en GitHub Pages

1. Sube todo el contenido de esta carpeta a la raíz de tu repositorio. index.html debe quedar directamente en esa raíz.
2. En el repositorio abre Settings > Pages.
3. En Build and deployment elige Deploy from a branch, selecciona la rama que contiene los archivos y la carpeta / (root). Guarda.
4. Espera a que termine la publicación y abre el enlace que muestra GitHub Pages.

Conserva los nombres de los archivos para que funcionen las referencias. Los PDF incluidos podrán consultarse desde el sitio publicado.

## Usar el simulador

Elige un modo, pulsa Iniciar examen y responde diez preguntas. Cada opción seleccionada confirma la respuesta y abre su explicación. Pulsa Siguiente pregunta para continuar.

El progreso se guarda con localStorage por navegador y dispositivo. Se conserva al cerrar la pestaña. Desde Progreso puedes exportar o importar una copia JSON y reiniciar las estadísticas previa confirmación. Para trasladar el avance de la versión local a GitHub Pages, expórtalo en la primera e impórtalo en la segunda.

También puedes abrir index.html con doble clic desde esta carpeta. Las preguntas y explicaciones funcionan sin conexión. Los enlaces a artículos y videos requieren internet.

coverage-report.md contiene el inventario de fuentes, la matriz de cobertura y las limitaciones de revisión.
